# Proposed Domain Rules

Status: `PROPOSED`. Herkunft: `04-DOMAIN-RULES.md`.

- 56 Tage, feste Mechanik, kalenderbezogene Anwendung.
- Programminstanz pro Athlet; Program Run pro abgegrenztem Mannschaftspilot.
- Check-in vor Completion; kein falscher Fortschritt bei Save-Fehler.
- Journal und freie Reflexion bleiben privat.
- Coach sieht operative Einzelaktivitaet und geschuetzte Teamaggregate.
- Sensible Aggregate erst ab n=5, niedrige Konfidenz bis n=10.
- Consent ist freiwillig und beeinflusst Evidence, nicht Produktzugang.
- Assessments und Development Index sind Messanker, keine Diagnose.
