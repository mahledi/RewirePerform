# Proposed UI Rules

Status: `PROPOSED`. Herkunft ueberwiegend `CONFIRMED_FROM_CHAT`.

- ruhig, hochwertig, professionell, mobile-first.
- direkte Information vor dekorativer Visualisierung.
- jeder Flow-Schritt beginnt oben und reagiert sofort.
- Pflichtantworten blockieren Weiter direkt.
- Voice optional, Tippen gleichwertig.
- klare Athletensprache: Situation, Handlung, Nutzen.
- keine abstrakte Fachsprache, Kartenverschachtelung oder redundante Hilfecopy.
- Coach sieht Zahlen und neutrale Beobachtungen, keine Handlungsanweisung.
- Accessibility und Text-Fit gehoeren zur Definition of Done.
