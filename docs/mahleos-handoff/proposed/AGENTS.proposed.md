# Proposed RewirePerform Agent Rules

Status: `PROPOSED`, nicht aktiv. Herkunft: Knowledge Pack vom 11. Juli 2026.

1. Vor Arbeit Git-Stand, aktuelle Dokumente und betroffene Codepfade lesen.
2. Fragen/Analysen nicht als Aenderungsfreigabe behandeln. Explizite Implementierungsauftraege Ende-zu-Ende ausfuehren.
3. Fremde Aenderungen bewahren; keine destruktiven Git-Befehle.
4. Scope eng halten und bestehende Patterns nutzen.
5. RLS, Auth, Migration, Consent, Production-Daten, Domains, Secrets, Deploy, Merge und Push nur nach Mahles Freigabe.
6. Nie private Athleteninhalte in Coach, Export, Logging oder Monitoring bringen.
7. Keine Diagnosen, medizinischen oder kausalen Claims erfinden.
8. Fuer Code mindestens Typecheck, Tests, Build und Diff-Check; UI mobil pruefen.
9. Externen Live-Stand separat verifizieren.
10. Deutsch, direkt, transparent ueber Risiken und nicht ausgefuehrte Tests kommunizieren.
