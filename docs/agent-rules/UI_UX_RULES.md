# UI and UX Rules

Quelle: aktive Kontextregeln `RP-UX-*` und bestaetigte Chatregeln.

- ruhig, hochwertig, professionell, vertrauenswuerdig; keine generische KI-Optik.
- mobile/iPhone/Homescreen zuerst, danach Desktop.
- nach `Weiter` oder Navigation beginnt der neue Abschnitt sofort oben, ohne sichtbare Scrollanimation.
- Buttons geben direkt Press-/Loading-Feedback; Error-, Offline- und Retry-Zustaende sind Teil der Funktion.
- Pflichtantworten blockieren den naechsten Schritt an Ort und Stelle.
- Voice ist optional, Tippen gleichwertig; Transkript bleibt beim Stoppen erhalten; redundante Voice-Tipps vermeiden.
- Spielertexte sind direkt, ernst, sportartenneutral und fuer Athleten ohne Mentaltraining-Vorwissen verstaendlich.
- Reihenfolge: reale Situation, konkrete Handlung, kurzer Nutzen. Eine Aussage pro Satz. Fachbegriffe sofort uebersetzen.
- Coach-Teamzustand nutzt direkte Zahlen und neutrale Beobachtungen, keine dekorativen Graphen, Team-Bereitschaft-Gesamtzahl oder Handlungsanweisung.
- keine unnötige Kartenverschachtelung, Hilfecopy, Textueberlaeufe oder gequetschte Controls.
- Landingpage deutet weiteren Inhalt im ersten Viewport an, ohne unprofessionelle Pfeile oder stoerende Browserleisten-Controls.

Wenn aktuelle UI dem Kontext widerspricht, nicht blind umschreiben: Konflikt melden und Task-Scope bestaetigen.
